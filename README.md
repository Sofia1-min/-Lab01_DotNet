Главные выводы:
1. Я убедилась, что `int / int` в C# — это не то же самое, что в Python:
В C# деление целых чисел (int / int) даёт целый результат. 10 / 3 =
3, а не 3.333.... Чтобы получить дробный результат, хотя бы одно число должно быть
double: 10.0 / 3 = 3.333...
2. Я поняла, что в C# тип переменной указывается, и это отличает его
от Python. Компилятор проверяет типы ещё до запуска программы — так
ошибки ловятся раньше. При этом `var` — это не динамическая типизация,
а автоматическое определение типа один раз при объявлении.
3. Я освоила полный цикл работы с Git: `git init -b main` создаёт репозиторий,
`git add .` добавляет файлы в staging area, `git commit -m "..."` сохраняет
снимок проекта, а `git push` отправляет коммиты на GitHub.

 Ответы на вопросы:
1. Console.Write() выводит текст без перехода на новую строку, а
Console.WriteLine() — с переходом. Write() удобно использовать
для приглашения к вводу, чтобы пользователь вводил данные в той же строке.
2. Программа не скомпилируется — возникнет ошибка. В C# тип переменной
указывается явно, и компилятор проверяет типы до запуска. Число 3.14
относится к типу double, а не int. Нужно либо использовать double,
либо явно преобразовать: (int)3.14 (тогда получится 3).
3. Потому что при делении двух целых чисел (int / int) C# выполняет
целочисленное деление — дробная часть отбрасывается. Чтобы получить
дробный результат, хотя бы одно число должно быть double, например:
(double)10 / 3 или 10.0 / 3. Тогда результат будет 3.333...
4. var — это автоматическое определение типа компилятором по значению
при объявлении. Но, в отличие от Python, тип определяется один раз
и больше не меняется. То есть var — это не динамическая типизация,
а сокращённая запись: var x = 5; равносильно int x = 5;.
